# Reversi Sense（ビルド成果物）

初心者育成型のリバーシ。**一手ごとに強さが見える。**

打つ場所を自分で選ぶまで、順位も評価値も最善手も表示しません。
選んだ瞬間に全ての手の順位が出て、選んだ手の強さが音とエフェクトで返ります。

**評価を見てからの選び直しは、既定でできません。**
それを許すと「候補を順に試して1位を探す」遊びになり、
測っているのが最初の判断力ではなくなるためです。
設定で許可に切り替えられます。

**遊ぶ:** https://pysk8zfc4z-byte.github.io/reversi-coach-web/

## このリポジトリについて

**ビルド成果物だけを置いています。**ソースコードは含みません。

## 動作について

- **端末内で完結します。**外部への通信を一切行いません
- 対局の記録はブラウザの localStorage にだけ保存されます。サーバーへは送りません
- ログイン・課金・広告・アクセス解析はありません
- オンライン対戦はありません。AI との対局と、同じ端末での二人対戦だけです
- 効果音と背景の音は WebAudio で合成しています。音源ファイルは含みません
- ロック画面やコントロールセンターに再生ウィジェットを出しません

### 音が鳴らないとき

iPhone は本体側面の**着信スイッチが消音になっていると、ブラウザの音が出ません。**
スイッチを鳴動側にしてください。

背景の音は既定で切です。「ルール・設定 → 音と振動 → 背景の音」で入にできます。
ときどき静かな単音が鳴るだけで、鳴り続けることはありません。
